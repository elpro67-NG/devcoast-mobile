# Identidad gráfica DevCoast integrada

Se usaron las dos imágenes proporcionadas sin redibujar ni modificar sus elementos.

- `assets/images/devcoast_icon.png`: ícono cuadrado original.
- `assets/images/devcoast_logo_horizontal.png`: logo horizontal original.
- El logo horizontal aparece en bienvenida e inicio de sesión/registro.
- El ícono aparece en la tarjeta principal y en la barra superior.
- Se actualizan los íconos de lanzamiento Android y los íconos/favicon web.
- Se conservan las pantallas, servicios HTTP y lógica de autenticación existentes.

Para ejecutar: `flutter pub get` y `flutter run -d chrome` (o el dispositivo Android configurado).

No se ha verificado una compilación local porque Flutter no está instalado en este entorno.
